# OOBB project instructions

Before creating or revising presentation renders, read the [OOBB render style guide](RENDER_STYLE.md). Apply it to renders made with this library in downstream OOBB projects as well.

For project README images, illustrated assembly instructions or repeatable presentation packages, also read [the presentation workflow](presentation/README.md) and [technical presentation style](presentation/STYLE.md). Use its AI-generated notice, verified hardware links, part manifest and render-and-review process. Preserve explicit user requirements.
