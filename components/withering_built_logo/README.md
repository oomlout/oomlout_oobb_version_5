# withering_built_logo

Rounded-square BUILT building-expertise logo badge. The supplied SVG paths are
subtracted from the top face for engraving or colour inlay. The OpenSCAD SVG is
normalized to a 1 mm square and omits the source file's white background.

This component supports the same variables as `withering_bvu_logo` and
`withering_hbbd_logo`.
