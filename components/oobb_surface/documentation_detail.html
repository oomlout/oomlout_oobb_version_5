Component Detail

oobb_surface

OOBB Geometry Primitives: Surface

Creates an OpenSCAD heightmap surface from an image, normalizing the source to 1000 pixels wide and scaling width, height, and relief depth in millimeters.

Category: OOBB Geometry Primitives
Returns: List of geometry component dicts.
Aliases: None

Sample Images

`oobb_surface` includes `icon.png` as a local documentation sample image and writes a normalized 1000-pixel-wide PNG beside each generated SCAD file. The generated SCAD references that copied PNG by filename only.

More Details

oobb_surface

OOBB Geometry Primitives: Surface

Creates an OpenSCAD heightmap surface from an image, normalizing the source to 1000 pixels wide and scaling width, height, and relief depth in millimeters.

The source PNG is resized into the same directory as the generated SCAD module, and the SCAD references that local PNG by filename only.
