More Details

withering_hbbd_logo

Withering HBBD Logo

Rounded-square badge component using the HBBD checkerboard SVG. The black logo regions are subtracted from the top face, making the component suitable for a shallow recess or a contrasting-colour inlay.

The OpenSCAD import uses the local image_scad.svg, normalised to a 1 mm square and converted to paths so it does not depend on a locally installed font.
