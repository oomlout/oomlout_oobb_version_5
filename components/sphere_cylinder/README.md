# sphere_cylinder

**OPSC Composite Shapes: Sphere Cylinder**

Cylinder with rounded top and bottom outside edges, intended as a drop-in rounded replacement for `cylinder`.

## Returns

List of geometry component dicts.

## Variables

| Name | Description | Type | Default |
|------|-------------|------|---------|
| r | Outer cylinder radius in mm. | number | 1 |
| h | Cylinder height in mm. | number | 1 |
| radius_rounded | Rounded edge radius in mm. | number | 1 |
| center | Match OpenSCAD cylinder center behaviour. | boolean | False |

## Sample Notes

show normal `r`/`h`, friendly `diameter`/`depth`, and centered cylinder usage.
